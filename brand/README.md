# Brand assets — organization avatar

Ready-to-upload organization avatar for github.com/LinkResan (1024x1024 PNG,
built from the canonical site mark `frontend/app/icon.svg`).

## Upload (web only — GitHub has no API for avatars)

1. Download `linkresan-org-avatar.png` (raw file view -> Download).
2. GitHub -> LinkResan organization -> **Settings** -> **General** ->
   **Profile picture** -> *Upload new picture* -> select the file ->
   crop to full square -> **Save**.
3. Verify on https://github.com/LinkResan.

`linkresan-org-avatar-alt.png` is the inverted variant (blue glyph on white).
